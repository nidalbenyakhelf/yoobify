# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-11-06

### Added
- ✅ **Deezer API Integration** — Full support for public Deezer playlists
- ✅ **Track Display** — Show playlist info, track list with album art and artist names
- ✅ **Audio Previews** — 30-second preview player for each track
- ✅ **Error Handling** — User-friendly error messages for invalid URLs or failed requests
- ✅ **Loading States** — Visual feedback during API calls
- ✅ **Responsive Design** — Mobile-first layout that works on all devices
- ✅ **GitHub Actions CI/CD** — Automated deployment to GitHub Pages
- ✅ **Contributors Section** — Dynamic display of GitHub contributors
- ✅ **FAQ Section** — Common questions answered
- ✅ **Platform Comparison** — Honest comparison with alternatives

### Changed
- Updated README to reflect working Deezer integration
- Improved code structure with modular JavaScript (IIFE pattern)
- Enhanced accessibility with ARIA labels and semantic HTML
- Added XSS protection with HTML sanitization

### Fixed
- Mobile menu toggle functionality
- Smooth scroll behavior for anchor links
- Form submission with Enter key support

## [0.1.0] - 2026-11-06

### Added
- Initial project structure with professional open-source setup
- Landing page with linear design (inspired by Brave browser)
- Basic sections: Hero, How It Works, Platforms, Algorithm, FAQ, Contribute
- GitHub repository with MIT License
- Contributing guidelines and Code of Conduct
- Architecture documentation
- GitHub Actions workflow for automated deployment
